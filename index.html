01 / ABOUT

See what dependencies cost

ModScan finds project node_modules directories and turns their paths, sizes, ages, and status into one keyboard-driven terminal view.

  1. Run ModScan from the directory you want to inspect.
  2. Press Enter to scan the current tree, or start with --global for a broader search.
  3. Sort and filter the results to find large or old dependency directories.
  4. Review the exact project and path before choosing any deletion action.

02 / CAPABILITIES

A clear terminal inventory

Local scan
Search the current working directory and its visible subdirectories for project node_modules folders.
Broader scan
Use --global to search the home folder, common development locations, and available Windows drives. Inaccessible, hidden, cache, and selected system paths are skipped.
Sort
Order results by size, modification date, project name, or filesystem path.
Filter
Show all, active, deleted, large, or old entries. Large means over 100 MB; old means more than 30 days.
Track
See the active directory count, combined size, and space removed during the current session.

03 / INSTALL

Run with npm

Try ModScan without a global installation:

$ npx modscan

Or install the command globally:

$ npm install -g modscan
$ modscan

Requires Node.js 10 or later and a terminal with Unicode support.

04 / DELETION

Deletion is immediate

[ PERMANENT ACTION ]

Capital D or lower-case dd recursively deletes the selected node_modules directory immediately.

The current v1.0.1 release asks for no confirmation and does not move the directory to Trash. There is no built-in rollback. Verify the selected path before using either shortcut.

05 / PRIVACY

Local runtime, no telemetry

The current ModScan runtime has no account, analytics, advertising, tracking, cloud service, or network-request code. It reads local directory metadata and a parent project's package.json name to build the terminal view.

Scan state is kept in memory. ModScan does not create a scan database or upload scan results to Kaizōsha.
